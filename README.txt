SANON LIFE — Projet Android (code source)

Ce ZIP n'est PAS un APK installable directement.

Pour produire un APK :
1. Installer Android Studio sur un ordinateur.
2. Décompresser le ZIP et ouvrir le dossier SANON_LIFE_Android dans Android Studio.
3. Attendre la synchronisation Gradle et l'installation éventuelle des composants Android SDK.
4. Menu Build > Build Bundle(s) / APK(s) > Build APK(s) (le libellé peut varier selon la version).
5. Récupérer app/build/outputs/apk/debug/app-debug.apk.
6. Transférer l'APK sur Android et autoriser l'installation depuis cette source si Android le demande.

Fonctionnement : application locale WebView, sans serveur, sans connexion IA.
Les données restent dans le stockage local de l'application et peuvent être perdues en cas de désinstallation.
Ne pas saisir de données confidentielles de tiers dans cette version.
